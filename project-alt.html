CRM-система для отдела продаж

Описание проекта

Проект направлен на разработку CRM-системы для автоматизации работы отдела продаж. Система должна обеспечивать ведение клиентской базы, контроль сделок, управление задачами сотрудников и формирование аналитических отчётов.
